# 💬 레퍼런스 메모 — 카톡 '나와의 채팅' 스타일 메모장

사진·링크·짧은 메모를 카카오톡 **'나와의 채팅'** 처럼 쌓아 두는 개인 레퍼런스 수집 앱입니다.
정적 웹앱(PWA)이라 GitHub Pages 에 올리면 끝이고, Supabase 무료 플랜을 연결하면 **폰(Android Chrome)과 PC가 자동으로 동기화**됩니다.
Supabase 를 연결하지 않아도 **로컬(IndexedDB) 모드**로 바로 쓸 수 있습니다.

## 1. 주요 기능

| 구분 | 내용 |
| --- | --- |
| 상단 탭 4개 | **🖼️ 사진 · 🔗 링크 · 📝 메모 · 🕒 타임라인** — 사진 메모는 사진 탭에만, 링크 메모는 링크 탭에만, 사진·링크가 없는 글자 메모는 메모 탭에만 보입니다(중복 없음). 기본 진입은 🖼️ 사진 탭 |
| 🕒 타임라인 | 사진·링크·글자 메모를 **구분 없이 한 번에, 최신순**(가장 최근에 쓴 항목이 맨 위)으로 모아 보는 피드 탭. 각 항목 위에 `🔗 링크` `🖼️ 사진 2` `📝 메모` 종류 배지가 붙어 섞여 있어도 바로 구분됩니다. 타임라인에서 보낸 메모는 타임라인에 그대로 쌓입니다 |
| 메모 탭 | 카톡 '나와의 채팅' 모양(날짜 구분선 `2026년 11월 21일 토요일`, 우측 노란 말풍선, 작성 시각 `오후 4:45`, '최신 메시지 ↓'). 상단에 **메모 분류 칩**(전체 · 일반 · 시그스튜디오대본 · `+`)과 태그 칩 |
| 입력 | Enter = 줄바꿈, **Shift+Enter = 전송**(설정에서 끄기 가능), Ctrl/⌘+Enter = 항상 전송, 모바일 자동 높이조절 |
| 사진 | 여러 장 동시 선택, **PC 드래그앤드롭**, **Ctrl+V 붙여넣기**, 전송 전 썸네일 확인/취소, 1~9장 카톡식 그리드(+N), 전체화면 라이트박스(확대·좌우 넘김·저장) |
| 화질 | 첨부 시 **웹 최적화**(장변 1600px·JPEG 82%) 또는 **원본 유지** 선택 |
| 링크 | 본문의 URL 자동 감지 → 클릭 가능한 링크 + 도메인 링크 카드(메모와 함께 저장). **`https://` 없이 쓴 주소도 인식**(`youtube.com/shorts/…`, `www.naver.com`, `dedcool.com`), 이메일·소수점·파일명은 링크로 보지 않음 |
| 유튜브 | 유튜브 링크(`watch?v=` · `shorts` · `youtu.be` · `live`, `m.youtube.com`)는 **썸네일(`i.ytimg.com/vi/<ID>/hqdefault.jpg`) + 영상 제목** 카드로 표시. 제목은 oEmbed 에서 비동기로 받아 메모리·localStorage 에 캐시(실패하면 도메인·URL 만), 썸네일이 깨지면 조용히 파비콘 카드로 |
| 링크 분류 | 링크를 `패키지 관련 · 레퍼런스 · 디자인 정보 · 기타 정보` 4종(＋추가 가능)으로 나눠 `🔗 링크` 탭에서 칩으로 걸러 보기, 카드 배지·⋮ 메뉴로 바로 변경. 분류는 `links` jsonb(`{url, category}`)에 저장돼 폰↔PC 동기화 |
| 사진 분류 | 사진도 링크와 같은 4분류(+추가). 첨부하면 입력창 위 **🖼️ 사진 분류 바**가 뜨고, `🖼️ 사진` 탭 상단 칩으로 걸러 보기, 셀 배지·라이트박스·⋮ 메뉴(`사진 분류`)로 변경. 분류는 `images` jsonb(`{key, path, w, h, category}`)에 저장돼 폰↔PC 동기화 |
| 분류 칩 바 | 입력창 위 링크·사진 분류 바와 `🔗 링크`·`🖼️ 사진` 탭 상단 칩은 **여러 줄로 펼쳐져**(PC 포함) 잘리지 않고 한눈에 보이고, 아주 많아지면 칩 바 안에서만 세로 휠 스크롤. 바 맨 끝 **`+` 칩**으로 새 분류를 만들면 그 분류가 바로 선택되고, 사진이 0장이어도 `🖼️ 사진` 탭에서 칩·`+`를 쓸 수 있음 |
| 분류 배지 | 말풍선 위에 `📦 패키지 관련 · 🎨 레퍼런스 · 💡 디자인 정보 · 📌 기타 정보 · 📝 일반 · 🎬 시그스튜디오대본 · 📁 <직접 추가>` 배지를 표시(누르면 바로 분류 변경) |
| 메모 분류 | 글자 메모는 `일반 · 시그스튜디오대본`(+추가)으로 나눕니다. 분류는 DB 스키마 변경 없이 `tags` 의 내부 마커(`__mcat:`)로 저장돼 폰↔PC 동기화되고, 화면(태그 목록·자동완성·말풍선)에는 보이지 않습니다. 메모 탭에서 보낸 글은 본문에 주소가 있어도 링크 카드로 빠지지 않습니다 |
| 링크 → 메모 옮기기 | 링크 카드 배지 시트의 **`📝 이 분류 N개를 메모 탭으로 옮기기`**, 또는 ⋮ → `📝 메모 탭으로 옮기기` — 링크 카드를 걷어내고 글자만 메모 탭 분류로 옮깁니다 |
| 태그 | `#화장품` 처럼 쓰면 자동 파싱 → 상단 가로 스크롤 태그 필터(`전체`, `#태그` + 건수), 입력 중 태그 자동완성 |
| 검색 | 메모 본문·태그·링크 통합 검색 |
| 보기 | 🖼️ 사진 모아보기 / 🔗 링크 모아보기 / 📝 메모 / 🕒 전체 타임라인 |
| 메모 관리 | 말풍선·사진 갤러리 셀·링크 카드 **길게 누르기**(또는 ⋮ / 우클릭) → 복사 · 수정 · 핀 고정 · 분류 · 삭제 |
| 잠금 | **Supabase 이메일 로그인이 기본**(로그인 전에는 메모·검색·사진이 보이지 않는 전체화면 게이트) + 기기 화면용 4~6자리 PIN(선택) |
| 보안 | 사진 버킷 **비공개**, DB·스토리지 모두 `auth.uid() = user_id` RLS, 사진 경로 `<user_id>/<메모id>/<파일>`, 로그아웃 시 기기 캐시 삭제 |
| PWA | manifest + 앱 아이콘 + 서비스 워커 → Android Chrome '홈 화면에 추가', 오프라인에서도 열림. **새 버전이 배포되면 `skipWaiting`+`controllerchange` 로 자동 새로고침**(입력 중이면 알림만)되고, 안 되면 설정 ⚙️ → **`캐시 지우고 새로고침`** |
| 동기화 | Supabase(PostgreSQL + Storage), 로그인 세션 자동 refresh, 로컬 우선 저장 후 자동 업로드/다운로드(기본 8초), 오프라인 큐, 마지막 쓰기 승리 |

## 3. 바로 써보기 (로컬 모드, 30초)

`index.html` 을 그냥 더블클릭하면 브라우저 보안 정책 때문에 IndexedDB·서비스워커가 막힐 수 있습니다. **로컬 서버로 여는 것을 권장**합니다.

```bash
cd memo-app
python3 -m http.server 8080
# 브라우저에서 http://localhost:8080/index.html
```

또는 VS Code 의 **Live Server** 확장을 쓰면 됩니다.
이 상태에서 상단 배지는 **`로컬`** 로 표시되고, 데이터는 그 브라우저에만 저장됩니다.

## 4. Supabase 연결 (로그인 + 폰·PC 자동 동기화)

### ① 프로젝트 만들기
1. <https://supabase.com> 로그인 → **New project**
2. 이름·DB 비밀번호 입력, 리전은 `Northeast Asia (Seoul)` 권장 (무료 플랜)

### ② SQL 실행
1. 대시보드 → **SQL Editor** → **New query**
2. `supabase_setup.sql` 파일 내용 전체를 붙여넣고 **RUN**
3. 맨 아래 확인 쿼리에서 `bucket_public = false`, `memo_policies = 4`, `storage_policies = 4` 이면 정상

이 SQL 이 만드는 것 (기본값 = **로그인 필수 + 비공개 사진**)
- 테이블 `public.memos` (id, **user_id**, content, tags, links, images, pinned, deleted, created_at, updated_at)
- RLS 정책 4종: 로그인한 본인(`auth.uid() = user_id`)만 SELECT / INSERT / UPDATE / DELETE
- 스토리지 버킷 `memo-images` **비공개(public = false)**, 10MB, 이미지 MIME 제한
- `storage.objects` 정책 4종: `(storage.foldername(name))[1] = auth.uid()` — 사용자별 폴더 격리
- 예전 'anon 전체 허용 / 공개 버킷' 설정이 있으면 함께 정리

### ③ 로그인 계정 준비 (회원가입은 끔)
1. **Authentication → Sign In / Providers → Email** → *Allow new users to sign up* **OFF**
2. **Authentication → Users → Add user** → 본인 이메일·비밀번호 입력, *Auto Confirm User* 체크 → **Create user**

> 앱에는 회원가입 화면이 없습니다. 계정은 이렇게 대시보드에서 1개만 만들어 두고, 앱에서는 그 계정으로 로그인합니다.

### ④ 키 복사
대시보드 → **Project Settings → API**
- **Project URL** : `https://xxxxxxxxxxxx.supabase.co`
- **anon public** : `eyJhbGciOiJIUzI1NiIs...`

> `service_role` 키는 절대 웹앱에 넣지 마세요. anon 키만 사용합니다.

### ⑤ config.js 수정

```js
window.MEMO_CONFIG = {
  supabaseUrl: 'https://xxxxxxxxxxxx.supabase.co',
  supabaseAnonKey: 'eyJhbGciOiJIUzI1NiIs...',
  table: 'memos',
  bucket: 'memo-images',
  syncIntervalMs: 8000        // 자동 동기화 주기 (느리게: 15000~30000)
};
```

### ⑥ 확인
새로고침 → **로그인 화면**이 먼저 뜹니다(로그인 전에는 메모가 화면에 올라오지 않습니다).
③에서 만든 이메일·비밀번호로 로그인하면 상단 배지가 **`동기화됨`** 으로 바뀝니다.
설정(⚙️) → **계정**에서 로그인한 이메일을 확인하고 **로그아웃**할 수 있습니다. 같은 계정으로 로그인한 다른 기기는 메모와 사진을 자동으로 내려받습니다.

> 무료 플랜 한도(2026년 기준): DB 500MB, Storage 1GB, 전송 5GB/월. 사진은 웹 최적화(장변 1600px, 장당 200~400KB)로 올리면 1GB 에 3,000~5,000장 정도 들어갑니다.

## 5. GitHub Pages 배포

GitHub Pages 는 **저장소 루트** 또는 **`/docs` 폴더**만 배포합니다. 두 가지 중 편한 방법을 쓰세요.

**방법 A — 저장소 루트에 두기 (가장 간단)**
```bash
# 새 저장소를 만들고 memo-app 폴더의 "내용물"을 루트에 올린다
cd memo-app
git init
git add .
git commit -m "memo app"
git branch -M main
git remote add origin https://github.com/<계정>/<저장소>.git
git push -u origin main
```
GitHub → **Settings → Pages** → Source `Deploy from a branch` → Branch `main` / `/ (root)` → Save
→ `https://<계정>.github.io/<저장소>/` 접속

**방법 B — 폴더 이름을 `docs` 로**
```bash
mkdir -p docs && cp -r memo-app/* docs/
```
Settings → Pages → Branch `main` / `/docs`

배포 후에는 **HTTPS** 이므로 서비스 워커·PWA 설치가 정상 동작합니다.
`config.js` 에 키를 넣었다면 그대로 배포하면 되고, 키를 숨기고 싶다면 배포 후에만 값을 채우는 방식(별도 빌드)을 쓰세요. anon 키는 공개되어도 되는 키이지만, 아래 8번 보안 항목을 함께 읽어 주세요.

## 6. Android 홈 화면에 추가 (앱처럼 쓰기)

1. Chrome 에서 배포 주소 접속
2. 우측 상단 **⋮ → 홈 화면에 추가**(또는 '앱 설치')
3. 아이콘을 누르면 주소창 없는 전체화면 앱으로 열립니다 (standalone)

설정 시트의 **홈 화면에 추가** 버튼도 사용할 수 있습니다(설치 프롬프트가 뜰 때).

## 7. 사용법 한눈에

| 하고 싶은 것 | 방법 |
| --- | --- |
| 메모 보내기 | 하단 입력 → **전송**(↑) 또는 **Shift+Enter** (Enter 는 줄바꿈) |
| 로그인 / 로그아웃 | 첫 화면에서 이메일·비밀번호 입력 → **로그인** · ⚙️ → 계정 → **로그아웃** |
| 사진 여러 장 | `＋` → 여러 장 선택 → 썸네일 확인 → 전송 |
| PC에서 사진 | 파일을 창에 **끌어다 놓기** / 캡처 후 **Ctrl+V** |
| 태그 | 본문에 `#화장품` 처럼 입력. `#` 버튼을 누르면 추천 태그가 뜹니다 |
| 태그로 모아보기 | 상단 태그 칩 탭 (다시 누르면 해제) |
| 찾기 | 🔍 → 메모·태그·링크 검색 |
| 사진만 / 링크만 / 글자만 | 상단 `🖼️ 사진` / `🔗 링크` / `📝 메모` 탭 |
| 메모 분류 | `📝 메모` 탭에서 입력창 위 분류(일반·시그스튜디오대본·`+`)를 고르고 보내면, 주소가 섞여 있어도 글자 메모로 저장됩니다 |
| 링크 분류 | 주소를 입력하면 입력창 위에 분류 바가 뜨고, 탭 한 번으로 고릅니다(안 고르면 `기타 정보`). `🔗 링크` 탭 상단 칩으로 걸러 보고, 카드 오른쪽 배지나 ⋮ → `📁 링크 분류` 로 바꿉니다 |
| 분류 추가 | 분류 바 맨 끝 **`+`** → 이름 입력 → 그 분류가 바로 선택됩니다. 분류가 많아지면 바가 여러 줄로 펼쳐집니다 |
| 분류 지우기 | 항목이 **0건**인 직접 추가한 분류 칩의 **✕** 를 누르기(길게 누르기·우클릭도 됨) |
| 복사·수정·고정·삭제 | 말풍선·사진 셀·링크 카드 **길게 누르기** (PC는 ⋮ 또는 우클릭) |
| 사진 크게 보기 | 사진 탭 → 화면 꽉 차게, 다시 탭하면 확대, `저장` 으로 내려받기 |
| 잠그기 | ⚙️ → PIN 잠금 설정 (4~6자리) |
| 백업 | ⚙️ → JSON 으로 백업 |

## 8. 동기화·보안 동작 방식

**로그인 (기본값)**
- `config.js` 에 Supabase URL·anon key 가 있으면 앱은 **로그인 없이는 아무 메모도 보여주지 않는 전체화면 게이트**로 시작합니다. 로그인 전에는 메모 목록·검색·사진·태그가 DOM 에도 올라오지 않습니다.
- 세션(`access_token` / `refresh_token` / `expires_at` / `user`)은 '로그인 유지' 선택 시 localStorage, 해제 시 sessionStorage 에만 저장하고, **만료 60초 전이거나 401 응답을 받으면 자동으로 refresh** 합니다. refresh 가 거부되면 즉시 로그인 화면으로 돌아갑니다.
- `config.js` 가 비어 있으면 로그인 없이 **로컬 미리보기 모드**(IndexedDB, 이 기기에만 저장)로 동작합니다.
- 설정 ⚙️ → 계정에 로그인한 이메일이 표시되고 **로그아웃**하면 세션이 지워지며, 이 기기의 메모·사진 캐시도 함께 삭제됩니다. 계정을 바꿔 로그인하면 이전 계정 캐시는 섞이지 않도록 비웁니다.
- PIN 잠금은 로그인을 유지한 채 **이 기기 화면을 한 번 더 잠그는** 용도로 그대로 남아 있습니다.

**동기화**
- 모든 변경은 **먼저 기기에 저장**(IndexedDB)하고, 온라인이면 서버로 업로드합니다. 전송 실패분은 `dirty` 로 남아 다음 주기에 재시도합니다.
- 서버 → 기기는 `updated_at` 커서로 증분 다운로드하고, 같은 메모는 **더 최신 `updated_at` 이 이깁니다**(마지막 쓰기 승리).
- 불러온 기기 캐시는 항상 `normalize()` 를 거칩니다. **`__mcat:` 메모 분류가 붙은 메모는 `links` 를 빈 배열로 되돌리고 IndexedDB 에도 정리**하므로, 구버전이 남긴 '메모인데 링크로 보이던' 오염 캐시도 앱을 열면 즉시 📝 메모 탭으로 돌아옵니다(v1.3.1).
- 설정 → **캐시 지우고 새로고침** 은 올리지 못한 변경(`dirty`)이 없을 때 동기화 커서(`lastPull`)도 버려서 서버에서 처음부터 다시 받습니다.
- 삭제는 **소프트 삭제**(`deleted=true`)로 전파되고, 스토리지 사진 파일도 함께 삭제 요청합니다.
- 앱이 화면에 보이는 동안만 폴링합니다(기본 8초). 탭이 백그라운드면 멈춰서 무료 트래픽을 아낍니다.
- 메모 행에는 항상 `user_id` 가 들어가고(RLS 기준), 사진은 **비공개 버킷**의 `<user_id>/<메모id>/<파일>` 경로에 올라갑니다. 다른 기기에서는 그 경로를 **Bearer 토큰으로만** 내려받아 IndexedDB 에 캐시합니다. 공개 URL 은 쓰지 않습니다.

**보안 — 꼭 읽어 주세요**
- anon 키는 웹앱 소스에 들어가는 공개 키입니다. 그래서 기본 SQL 은 **anon 에 아무 권한도 주지 않고**, 로그인한 본인(`auth.uid() = user_id`)에게만 행과 파일을 엽니다. URL+anon 키를 알아도 로그인 비밀번호가 없으면 메모·사진을 읽을 수 없습니다.
- **회원가입은 꺼 두세요.** 켜 두면 누구나 계정을 만들 수 있습니다(SQL 이 아니라 Authentication 설정에서 끕니다).
- PIN 은 이 기기의 화면 잠금입니다. **PIN 해시만 localStorage** 에 있고 메모 자체의 보호는 로그인·RLS 가 담당합니다. PIN 을 잊으면 `localStorage` 의 `memo.pin.v1` 만 지우면 잠금이 풀립니다(메모는 그대로).
- 로그아웃 시 기기 캐시를 지우지만, 브라우저 개발자도구로 저장소를 직접 뒤질 수 있는 사람은 로그아웃 전 캐시를 볼 수 있습니다. 공용 PC 에서는 로그아웃 후 브라우저 데이터까지 지우는 것이 안전합니다.

## 10. 알려진 제한

- **이전 버전(공개 버킷)에서 올린 사진**은 `memos/<메모id>/...` 경로라서 새 비공개 정책(`<user_id>/...`)에서는 열리지 않습니다. 새 버전에서 사진을 다시 첨부해 주세요(글·링크는 그대로 유지됩니다).
- 실시간 push 는 없고 **폴링(기본 8초)** 입니다. 더 즉시성이 필요하면 Supabase Realtime 구독을 추가할 수 있습니다(`supabase_setup.sql` 4번 참고).
- 한 메시지당 사진 **20장**, 파일당 **10MB** 까지.
- JSON 백업은 **내보내기 전용**입니다(복원 UI 는 아직 없음).
- HEIC 등 일부 형식은 브라우저가 디코딩하지 못하면 썸네일이 비어 보일 수 있습니다(파일은 정상 저장).
- 폰에서 '공유 → 레퍼런스 메모' 로 바로 보내는 기능은 아직 없습니다(PWA 공유 대상 등록 필요).
- **유튜브 영상 제목**은 YouTube oEmbed 를 그대로 읽어 오므로, 오프라인이거나 영상이 삭제·비공개면 제목 없이 도메인·URL 만 표시됩니다(썸네일/링크는 그대로 열림).
